# アプリ屋はるき工房

製造現場出身の個人開発者「はるき（murota-h）」が、工場・お店・個人向けの業務改善アプリを作って配布しています。

🌐 **サイト**: https://murota-h.github.io/haruki-kobo/

---

## 作ったアプリ

| アプリ名 | 説明 | 技術 |
|---|---|---|
| KY活動デジタル化アプリ | 危険予知活動をタブレットで。AIキャラ＆ガチャ演出で現場が楽しく参加 | Flutter / AI連携 |
| もじもじチェンジャー | ことばをかわいくへんかんしてくれるAIアプリ | Flutter / AI文章生成 |
| 細内ナレッジコネクト | 職場の申し合わせ記録・みんなの声を管理するツール | Flutter |
| 製造現場の統計学習アプリ | 正規分布・管理図など工場で役立つ統計をわかりやすく学べる | Flutter |
| 部品写真リネームツール | 工業部品の写真をAIが認識して自動でファイル名を整理 | Flutter / Gemini API |
| 温度補正計算ツール | 素材の温度による寸法補正を自動計算するWebアプリ | Flutter Web / GitHub Pages |

---

## 得意なこと

- **製造業・工場向けDXツール**：点検記録・KY活動・作業手順のデジタル化
- **お店・個人向けアプリ**：注文管理・在庫確認・スタッフ連絡ツール
- **AI組み込み**：画像認識・文章生成（Gemini API / Claude API）
- **スモールスタート**：「システム会社に頼むほどじゃないけど、あったら便利」なアプリ

## 技術スタック

`Flutter` `Gemini API` `Claude API` `GitHub Pages` `Android APK` `Flutter Web`
